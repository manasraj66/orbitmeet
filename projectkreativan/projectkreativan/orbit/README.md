# Orbit

Orbit is a real-time meeting app starter project. See `docs/` for architecture, API, feature, deployment, and troubleshooting notes.

## Quick start

1. Copy `.env.example` to `.env` and configure values.
2. Install dependencies: `pip install -r requirements.txt`
3. Run `bash run.sh` (Linux/macOS) or `run.bat` (Windows).

This archive contains the requested project structure and starter placeholders; implement and configure the application modules before production use.
