# Orbit Meet 🚀

**Orbit Meet** is a real-time video conferencing web application designed to make online meetings simple, interactive, and accessible. Users can create meeting rooms, communicate with participants, share screens, and manage meetings through an intuitive web interface.

## ✨ Features

- 🎥 **Meeting Rooms** — Create and join online meetings.
- 💬 **Live Chat** — Communicate with participants in real time.
- 🖥️ **Screen Sharing** — Share your screen during meetings.
- 👥 **Participant Management** — View and manage meeting participants.
- 🎛️ **Host Controls** — Manage meeting permissions and participant access.
- 😀 **Reactions** — Express reactions during meetings.
- 🚪 **Waiting Room** — Support for participant approval workflows.
- 🔊 **Real-Time Signaling** — WebRTC signaling and WebSocket communication.
- 🛠️ **Admin Interface** — Access administrative tools for managing the application.

## 🧰 Tech Stack

- **Backend:** Python, FastAPI
- **Frontend:** HTML, CSS, JavaScript
- **Real-Time Communication:** WebSockets, WebRTC
- **Database:** Application database module
- **Deployment:** Docker and Docker Compose

## 🚀 Getting Started

### Prerequisites

- Python installed on your system
- pip package manager

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory containing `requirements.txt`.

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your environment variables using `.env.example` as a reference.

5. Run the application on Windows:

   ```powershell
   .\run.bat
   ```

   Alternatively, on Linux or macOS:

   ```bash
   ./run.sh
   ```

6. Open the local URL shown in your terminal.
